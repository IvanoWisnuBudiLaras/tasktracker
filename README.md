Penyelesaian Tugas Haltech

sebagai pengantar tasktracker ini adalah web aplikasi untuk mengelola task dan project tasktracker ini bertujuan memahami crud basic dalam web

- Membuat task dimana task terdiri dari judul, deskripsi, status(pending, inprogress, completed), 
- menggunakan quiiljs sebagai pembamtu dalam membuat rich text
- menggunakan mysql sebagai database
- menggunakan drizzle sebagai ORM
- menggunakan nextjs sebagai framework
- menggunakan shadcn ui sebagai component
- menggunakan tailwind css sebagai styling  
- menggunakan zod sebagai validasi
- menggunakan lucide-react sebagai icon
- menggunakan react-hook-form sebagai form 
- menggunakan jsonwebtoken sebagai authentikasi
- menggunakan bcryptjs sebagai hashing password
- menggunakan isomorphic-dompurify sebagai sanitasi input

saya menggunakan hal hal diatas bertujuan memahami bagaimana cara kerja nextjs, database, dan library lainnya agar bisa membangun web yang lebih kompleks nantinya seperti web e-commerce, sosial media, dan lain sebagainya namun tetep dengan struktur yang clean dan mudah dibaca
